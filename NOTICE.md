# Notice and Attribution

Open Prompt Archive contains two distinct classes of material:

1. **Original repository software/tooling and documentation** created for this project.
2. **Imported prompt/data records** originating from third-party sources.

The root `LICENSE` applies to original project software/tooling unless a file states otherwise. It does **not** automatically relicense imported third-party prompt/data content.

## Imported records

Every accepted third-party record must preserve, directly or through its source registry entry:

- source name;
- canonical source URL;
- upstream author or maintainer when known;
- upstream license identifier and license evidence;
- attribution text when required;
- retrieval date;
- source revision/commit/tag when available;
- provenance/integrity information.

Attributions for imported datasets will be generated from `sources/sources.yaml` and record metadata as sources are approved.

## Images and other media

A prompt license does not automatically establish redistribution rights for associated images, video, audio, trademarks, likenesses, or other media. External media is not mirrored by default and requires independent rights verification.

## Corrections

If you believe a source, attribution, license classification, or record is incorrect, open an issue with the affected record/source identifier and supporting evidence. Questioned content should be quarantined from redistribution until the issue is resolved.
